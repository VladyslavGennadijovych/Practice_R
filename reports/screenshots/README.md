# Походження скриншотів

Знімки отримано 26 жовтня 2026 року з фактично запущеного RStudio Server 2026.10.0+233 із R 4.5.3. Код `analysis.R` виконано командою `source("analysis.R")`; створено об’єкт `analysis_results` і збережені результати аналізу.

- `rstudio-code.png` — редактор із файлом `analysis.R`, хронологічним поділом даних і побудовою моделі.
- `rstudio-results.png` — консоль після команди `print(as.data.frame(analysis_results$metrics[c(1:5, 10:15), ]), row.names=FALSE)`.

Для читабельності використано штатне збільшення шрифту редактора й консолі та розгортання відповідної панелі. Файли PNG є знімками браузерного інтерфейсу; у Word і PDF вони вбудовані з підписами. Контрольні суми містяться в `reports/artifact-manifest.json`.
