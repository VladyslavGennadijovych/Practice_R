# Завдання для виробничої практики

**Тема:** «Прикладний статистичний аналіз даних із використанням мови програмування R».

**Мета роботи:** набути практичних навичок обробки, аналізу та візуалізації даних за допомогою мови програмування R, навчитися використовувати методи описової статистики, кореляційного та регресійного аналізу для дослідження реальних або змодельованих даних.

## Постановка завдання

Необхідно розробити програму мовою R для проведення статистичного аналізу набору даних, що містить різні числові показники. Дослідити основні характеристики даних, визначити можливі взаємозв'язки між показниками, побудувати графіки для наочного представлення результатів та використати статистичні методи для аналізу залежностей і прогнозування значень.

## Етапи виконання роботи

1. **Підготовка даних.** Завантажити набір даних із CSV-файлу або створити власний набір даних, що містить не менше 50 записів. Перевірити дані на наявність пропущених значень, повторюваних записів та помилок. За потреби виконати очищення й підготовку даних до подальшого аналізу.
2. **Описова статистика.** Обчислити основні статистичні показники для досліджуваних числових змінних, зокрема середнє значення, медіану, моду, дисперсію, стандартне відхилення, мінімальне та максимальне значення. Проаналізувати отримані результати й визначити основні характеристики набору даних.
3. **Візуалізація даних.** Побудувати гістограми, діаграми розмаху (boxplot) та діаграми розсіювання для графічного представлення даних. Використати графіки для виявлення особливостей розподілу значень, можливих відхилень і залежностей між досліджуваними змінними.
4. **Кореляційний аналіз.** Визначити коефіцієнти кореляції між обраними показниками. Встановити, чи існує взаємозв'язок між змінними, оцінити його напрям і силу. За потреби перевірити статистичну значущість виявлених зв'язків.
5. **Регресійний аналіз.** Побудувати лінійну регресійну модель для дослідження залежності одного показника від одного або кількох інших показників. Використати отриману модель для оцінювання впливу змінних і прогнозування можливих значень досліджуваного показника.
6. **Перевірка моделі.** Проаналізувати якість побудованої регресійної моделі за допомогою коефіцієнта детермінації R², оцінити статистичну значущість коефіцієнтів і дослідити залишки моделі. Визначити, наскільки добре модель описує наявні дані та чи можна використовувати її для прогнозування.
7. **Інтерпретація результатів.** Проаналізувати отримані статистичні показники, таблиці та графіки. Визначити основні закономірності й залежності між досліджуваними змінними. Сформулювати висновки щодо результатів аналізу та можливостей практичного застосування побудованої моделі.

## Інструменти та засоби реалізації

- Мова програмування R.
- Середовище розробки RStudio.
- Пакети ggplot2, dplyr та readr для обробки й візуалізації даних.
- Вбудовані функції R для обчислення статистичних показників, проведення кореляційного та регресійного аналізу.

## Очікуваний результат

Необхідно підготувати програмний код мовою R, набір оброблених даних, статистичні таблиці, графіки та результати побудови регресійної моделі. Оформити звіт, у якому описати етапи виконання роботи, використані методи, отримані результати та сформульовані висновки.

**Підсумковий продукт:** програмний модуль статистичного аналізу даних, який дає змогу завантажувати й обробляти дані, обчислювати основні статистичні показники, досліджувати взаємозв'язки між змінними, візуалізувати результати та виконувати прогнозування на основі побудованої статистичної моделі.
