# Practice_R

Програмний модуль для виробничої практики **«Прикладний статистичний аналіз даних із використанням мови програмування R»**. Програма виконує всі сім етапів [технічного завдання](docs/technical-assignment.md): підготовку даних, описову статистику, візуалізацію, кореляційний аналіз, лінійну регресію, перевірку моделі та інтерпретацію результатів.

Готовий звіт: [Word](reports/Practice_R_Report.docx) · [PDF](reports/Practice_R_Report.pdf).

## Запуск

Середовище містить R 4.5.3, `ggplot2`, `dplyr`, `readr`, стандартні пакети R та `renv`. Для відтворюваного встановлення у Linux x86_64 потрібні Bash, Git, `curl` і `sha256sum`:

```bash
bash scripts/setup-r.sh
source scripts/activate-r.sh
Rscript --vanilla analysis.R
```

Інсталятор перевіряє SHA256 micromamba 2.9.0 і встановлює залежності за [точним списком пакетів із контрольними сумами](environment/conda-linux-64.lock). Інструменти й кеші зберігаються поза репозиторієм, у `/workspace/.practice-r-setup`; micromamba також використовує реєстр `~/.conda`. На іншій Linux-машині перед установленням і наступними активаціями задайте власний каталог:

```bash
export PRACTICE_R_SETUP_ROOT="$HOME/.local/share/practice-r"
bash scripts/setup-r.sh
source scripts/activate-r.sh
```

У кожній новій оболонці Bash виконуйте `source scripts/activate-r.sh`. Це налаштовує R, компілятори, бібліотеку пакетів і кеші.

Для роботи в **RStudio** відкрийте [Practice_R.Rproj](Practice_R.Rproj), переконайтеся, що вибраний R має пакети `ggplot2`, `dplyr` і `readr`, та виконайте в консолі:

```r
source("analysis.R")
```

Проєкт використовує UTF-8 і не відновлює стару `.RData`. Актуальна програма та результати доступні без RStudio через `Rscript`.

Для цього звіту аналіз також реально виконано в **RStudio Server 2026.10.0+233**. Знімки інтерфейсу збережено в [reports/screenshots](reports/screenshots). Локальний сервер на Debian-сумісному Linux можна відтворити командою `bash scripts/start-rstudio.sh`; він використовує порт 8787 лише на loopback і зберігає свої файли поза репозиторієм. Скрипту потрібні `dpkg-deb` і доступ до `dl.dailies.rstudio.com`; він перевіряє офіційний SHA256 пакета.

## Дані та очищення

Джерело — документований набір [`datasets::airquality`](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/airquality.html) із R: 153 щоденні спостереження в Нью-Йорку за травень–вересень 1973 року. [Початковий CSV](data/raw/airquality.csv) отримано скриптом [scripts/export-data.R](scripts/export-data.R).

| Стовпець CSV | Значення та початкові одиниці | Змінна аналізу |
| --- | --- | --- |
| `Ozone` | Озон, ppb | `ozone_ppb` |
| `Solar.R` | Сонячна радіація, langley | `solar_langley` |
| `Wind` | Швидкість вітру, милі/год | `wind_ms = Wind × 0.44704` |
| `Temp` | Температура, °F | `temp_c = (Temp − 32) × 5 / 9` |
| `Month`, `Day` | Місяць і день спостереження 1973 року | `date` |

Виявлено 37 пропусків `Ozone` і 7 пропусків `Solar.R`, разом 44 порожні клітинки у 42 рядках. Повних дублікатів і значень, які порушують перевірені обмеження, немає. Застосовано аналіз повних спостережень без заповнення пропусків: [очищений набір](data/processed/airquality_clean.csv) містить **111 записів**. Значення, позначені правилом 1.5 IQR на boxplot, збережено, оскільки сама позначка не доводить помилку вимірювання.

Програма перевіряє числовий формат, набір і порядок стовпців, дублікати, пропуски, календарні дати та задані допустимі межі показників. Для іншого CSV із тією самою структурою й одиницями та окремого каталогу результатів:

```bash
Rscript --vanilla analysis.R data/raw/airquality.csv /tmp/practice-r-result
```

Вхідні стовпці мають бути `Ozone,Solar.R,Wind,Temp,Month,Day`; після очищення повинно залишатися щонайменше 50 спостережень. Рік у цьому модулі фіксовано як 1973. Некоректний формат або недостатній обсяг даних припиняють аналіз із повідомленням про причину. Сценарії прогнозу перевіряються на входження кожного показника в навчальний діапазон.

## Методи та результати

Описова статистика включає середнє, медіану, всі емпіричні моди за однакової максимальної частоти, вибіркову дисперсію, стандартне відхилення, мінімум і максимум. Програма створює гістограми, boxplot, діаграми розсіювання, кореляційну теплову карту та діагностичні графіки. Для шести пар показників розраховано кореляції Пірсона з довірчими інтервалами та BH-корекцією p-значень; кореляції Спірмена наведено для порівняння.

Основні кореляції з озоном на 111 повних спостереженнях: температура **r = 0.6985**, вітер **r = −0.6125**, сонячна радіація **r = 0.3483**. Це асоціації, а не доведені причинні ефекти.

Регресія `ozone_ppb ~ temp_c + wind_ms + solar_langley` навчена на перших 88 спостереженнях за часом (1 травня–6 вересня). Останні 23 спостереження (7–30 вересня) залишено для незалежної перевірки; модель на них не перенавчалася.

| Показник | Значення |
| --- | ---: |
| Навчальний R² | 0.6197 |
| Скоригований навчальний R² | 0.6061 |
| RMSE на тесті | 18.7735 ppb |
| MAE на тесті | 15.5773 ppb |
| R² на тесті | **−2.6784** |
| RMSE прогнозу середнім навчальної вибірки на тесті | 27.7399 ppb |

Від'ємний тестовий R² означає, що помилка моделі більша за відхилення тестових значень від їхнього власного середнього. Це середнє використовується лише для визначення R² і не є доступним заздалегідь прогнозом. Модель перевершує окремий базовий прогноз середнім **навчальної** вибірки, проте цього недостатньо, щоб вважати її надійною для прогнозування. Середній озон знижується з 47.48 ppb у навчальній частині до 21.52 ppb у тестовій; тестовий розкид також істотно менший.

Тест Шапіро–Вілка виявляє відхилення залишків від нормальності (p = 0.0000563), а правило Cook > 4/n позначає 5 впливових спостережень. Допоміжний тест неоднорідності дисперсії дає p = 0.3203; це не доводить виконання всіх припущень моделі. Прогнозні інтервали широкі, а для одного сценарію нижня межа від'ємна: вона збережена як результат лінійної моделі й не обрізана мовчки. Практичне використання потребує нових даних та додаткової перевірки моделі.

## Перевірки

```bash
source scripts/activate-r.sh
Rscript --vanilla tests/test-analysis.R
Rscript --vanilla scripts/check-r.R
bash scripts/check-native.sh
```

Виконано **5 інтеграційних перевірок програми**: відхилення неправильних стовпців, помилки числового формату, недостатньої кількості спостережень, коректне очищення дублікатів/фізично некоректних значень/неможливих дат, відтворення тестових прогнозів збереженою моделлю. Вони працюють у тимчасовому каталозі та не замінюють результати звіту.

Окремі **5 перевірок R** і **3 перевірки розширень C/C++/Fortran** підтверджують роботу інструментів середовища.
